# Reference methods

`evagent/` contains the project-owned EVAgent Python package and its offline
unit tests. `singlechain/` contains specialist model adapters, without vendor
source, checkpoints or installed environments. `catalog.json` preserves selected
historical model registration and limitation fields with local paths removed.

The benchmark evaluator at the repository root is independent of these packages.
You may produce the documented CSV format using any method.

Legacy adapters may require external repositories, licensed tools, model weights,
compatible environments and separately distributed benchmark data. Historical
availability metadata does not establish present readiness. Consult source
interfaces and the original model documentation before scientific inference.
